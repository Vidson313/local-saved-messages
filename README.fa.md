# پیام‌های ذخیره شده محلی

یک اپلیکیشن تحت وب سبک و خودمیزبان که قابلیت "Saved Messages" تلگرام را شبیه‌سازی می‌کند. آن را روی کامپیوتر شخصی خود میزبانی کنید و از هر دستگاهی در شبکه محلی به آن دسترسی داشته باشید — یک هاب جهانی برای کلیپ‌بورد و اشتراک‌گذاری فایل به‌صورت بلادرنگ.

## ✨ ویژگی‌ها

- **اشتراک‌گذاری متن بلادرنگ** — پیام‌های متنی را ارسال کنید که فوراً روی همه دستگاه‌های متصل از طریق Server-Sent Events (SSE) نمایش داده می‌شوند.
- **آپلود و ذخیره‌سازی فایل** — تصاویر، ویدئوها، اسناد و فایل‌های فشرده را آپلود کنید. فایل‌ها به‌صورت محلی روی کامپیوتر میزبان ذخیره می‌شوند.
- **دانلود عمومی** — هر دستگاهی در شبکه می‌تواند فایل‌های آپلود شده را دانلود کند.
- **چت‌های چندگانه** — پیام‌ها را در چت‌های جداگانه با نام‌های سفارشی و آواتارهای ایموجی سازماندهی کنید.
- **پین و ذخیره پیام** — پیام‌های مهم را پین کنید یا برای دسترسی سریع ذخیره کنید.
- **تشخیص خودکار لینک** — URL های موجود در پیام‌ها به‌طور خودکار به لینک‌های قابل کلیک تبدیل می‌شوند.
- **تب‌های رسانه و فایل** — تمام رسانه‌ها، لینک‌ها و فایل‌های به اشتراک گذاشته شده را در تب‌های اختصاصی مرور کنید.
- **کشیدن و رها کردن / چسباندن فایل** — فایل‌ها را بکشید و رها کنید یا از کلیپ‌بورد بچسبانید تا آپلود شوند.
- **پشتیبانی از PWA** — به‌عنوان یک اپلیکیشن مستقل روی موبایل و دسکتاپ نصب کنید.
- **حالت تاریک** — رابط کاربری مدرن با افکت glassmorphism و حالت تاریک پیش‌فرض.
- **بدون احراز هویت** — طراحی شده برای شبکه‌های محلی امن؛ بدون نیاز به ورود.

## 🚀 شروع به کار

### پیش‌نیازها

- [Node.js](https://nodejs.org/) نسخه ۱۸ یا بالاتر روی کامپیوتر میزبان نصب باشد.

### نصب

```bash
# ۱. مخزن را کلون کنید
git clone https://github.com/your-username/local-saved-messages.git
cd local-saved-messages

# ۲. وابستگی‌ها را نصب کنید
npm install

# ۳. سرور توسعه را اجرا کنید
npm run dev
```

اپلیکیشن در آدرس `http://localhost:3000` در دسترس خواهد بود.

### ساخت نسخه تولید

```bash
npm run build
npm start
```

### راه‌اندازی سریع در ویندوز

روی فایل [`start.bat`](start.bat) دابل کلیک کنید — این اسکریپت به‌طور خودکار Node.js را بررسی می‌کند، در صورت نیاز وابستگی‌ها را نصب می‌کند، پروژه را می‌سازد و سرور را راه‌اندازی می‌کند.

## 🌐 دسترسی از دستگاه‌های دیگر

۱. آدرس IP محلی کامپیوتر میزبان خود را پیدا کنید:
   - **ویندوز:** `cmd` را باز کنید → دستور `ipconfig` را بزنید → به دنبال `IPv4 Address` بگردید (مثلاً `192.168.1.5`)
   - **لینوکس/macOS:** دستور `ip addr` یا `ifconfig`
۲. روی هر دستگاهی که به همان وای‌فای متصل است، آدرس زیر را باز کنید:
   ```
   http://<YOUR_IP>:3000
   ```
   مثال: `http://192.168.1.5:3000`

> ⚠️ مطمئن شوید که فایروال شما اتصالات ورودی روی پورت `3000` را مجاز می‌داند.

## 🔌 endpoint های API

| متد | endpoint | توضیح |
|--------|----------|-------------|
| `GET` | `/api/messages?chatId=...` | دریافت پیام‌ها (قابل فیلتر بر اساس چت) |
| `POST` | `/api/messages` | ایجاد پیام متنی |
| `DELETE` | `/api/messages` | حذف پیام‌ها با شناسه |
| `GET` | `/api/messages/[id]` | دریافت یک پیام |
| `PATCH` | `/api/messages/[id]` | به‌روزرسانی پیام (پین/ذخیره) |
| `GET` | `/api/chats` | لیست تمام چت‌ها |
| `POST` | `/api/chats` | ایجاد چت جدید |
| `PATCH` | `/api/chats/[id]` | به‌روزرسانی چت (تغییر نام، آواتار) |
| `DELETE` | `/api/chats/[id]` | حذف چت و پیام‌های آن |
| `POST` | `/api/upload` | آپلود فایل (multipart/form-data) |
| `GET` | `/api/events` | جریان SSE برای به‌روزرسانی‌های بلادرنگ |

## 📦 ذخیره‌سازی داده‌ها

تمام داده‌ها به‌صورت فایل‌های JSON در پوشه `data/` ذخیره می‌شوند:

- `data/chats.json` — اطلاعات چت‌ها
- `data/messages.json` — تمام پیام‌ها

فایل‌های آپلود شده در `public/uploads/` ذخیره می‌شوند. هیچ پایگاه داده خارجی مورد نیاز نیست.
